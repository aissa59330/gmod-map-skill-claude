# gmod-map-skill-claude

Compétence (skill) Claude Code pour créer, optimiser et publier des maps Garry's Mod d'event
(générées en Python, compilées en ligne de commande, vérifiées en jeu, optimisées pour 100 joueurs et beaucoup de PNJ, sans Lua).

- La compétence : [`gmod-map-skill/gmod-map/SKILL.md`](gmod-map-skill/gmod-map/SKILL.md)
- Installation et prérequis : [`gmod-map-skill/gmod-map/README.md`](gmod-map-skill/gmod-map/README.md)
- Prompts prêts à l'emploi : [`gmod-map-skill/gmod-map/reference/PROMPTS.md`](gmod-map-skill/gmod-map/reference/PROMPTS.md)

Installation rapide : copier le dossier `gmod-map-skill/gmod-map` dans `C:\Users\<ton nom>\.claude\skills\`, puis redémarrer Claude Code.
